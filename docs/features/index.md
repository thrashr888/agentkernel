
# Features

Key capabilities beyond basic sandbox management.

- [Secrets](secrets.md) — Vault storage, proxy injection (Gondolin pattern), and file-based injection
- [Browser Automation](browser-automation.md) — Headless browser control inside sandboxes
- [Desktop App](desktop-app.md) — Native macOS GUI for sandbox management
- [Prometheus Metrics](metrics.md) — `/metrics` endpoint for Prometheus scraping
- [Durable Protocol](durable-protocol.md) — Shared schema and wire contract for durable runtimes and SDK interoperability
- [Durable Functions](durable-functions.md) — Orchestrate multi-step sandbox workflows with checkpointing
- [Durable Objects](durable-objects.md) — Stateful sandboxes with hibernation, alarms, and method dispatch
- [Compliance Mapping](compliance-mapping.md) — SOC 2, HIPAA, and PCI DSS control mapping
